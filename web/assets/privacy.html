Privacy Information

Draft for deployment review. This page documents the scaffold's technical behavior. It is not a complete GDPR privacy notice. The operator must add its identity, contact details, legal bases, retention periods, recipients, international transfer details, and users' rights before public deployment.

Network measurements

The application observes the client IP address of its HTTP peer to return IP information and run speed tests. Requests can appear in infrastructure logs according to operator configuration. The starter application does not include a database or user accounts.

Third-party STUN probes

On page load, browser-based WebRTC probes contact a list of public STUN servers operated by third parties. Those services can observe your network's public endpoint. Disable this feature in the source configuration before deployment if you cannot justify these requests or the providers' usage terms.

Cookies and analytics

This scaffold does not set tracking cookies or include advertising or analytics scripts. Adding any such technology requires a separate privacy and ePrivacy review.
